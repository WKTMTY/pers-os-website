# Website workspace

When the task is producing a **new design plan** for this workspace (`pers-os-website`), save the Markdown file under:

**`delivery/tasks/design-plan-<short-slug>-YYYYMMDD.md`**

Example: `delivery/tasks/design-plan-clarify-widget-performance-20260428.md`.

Use **`delivery/archives/`** only when **moving** completed or superseded plans out of tasks, not as the default drop location for active plans.

When implementing a plan or developing code, do not create or run any unit tests.
